# Baseline Policy

Approved/proven baselines are comparison evidence, not immutable screenshots.

When modifying an existing canonical surface, capture the relevant current state before changing it when practical. Compare resulting renders at the same route, viewport, locale, and meaningful state.

A material change to hierarchy, density, brand expression, or interaction requires the review to state whether the change is intentional.

A new baseline requires visual review, applicable UX review, accessibility verification, responsive verification, and completion-gate approval.
