# Reference Selection

1. Identify the surface and user job.
2. Identify the visual qualities that matter.
3. Select only relevant references.
4. Prefer proven Almsby patterns when they solve the problem.
5. Record what quality is being learned from each reference.
6. Explicitly identify qualities that should not be copied.

Do not flood an agent with a large gallery. Each reference needs a stable ID, relevance, extracted quality, intended use, and non-copy constraint.
