# Design Quality Contract

Material UI work requires, when applicable:

- `visual-direction.md`
- `design-plan.md`
- browser evidence
- visual review
- UX review for material interaction

The visual direction must identify user/product context, emotional outcome, composition, hierarchy, density, typography, imagery, interaction/state treatment, responsive strategy, reused patterns, new patterns, references, and baseline comparison where applicable.

New visual patterns require explicit rationale and remain `experimental` until reviewed.

A visual quality claim requires rendered evidence when a browser surface is available.

This contract does not decide whether a design is aesthetically good. It ensures the system produces the information and evidence required for meaningful judgment.
