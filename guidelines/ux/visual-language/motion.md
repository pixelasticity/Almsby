# Motion

Use motion to communicate change, hierarchy, or continuity. Avoid decorative motion, interaction delays, repeated attention-grabbing animation, or motion that masks weak static hierarchy.

Respect reduced-motion preferences. Essential information and interaction must not depend on animation.

Ask whether the interface would communicate the same meaning if animation were removed.
