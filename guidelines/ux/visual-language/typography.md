# Typography

Typography is an information-architecture tool, not decoration.

Use the existing Almsby type system unless a documented reason requires change. Establish hierarchy deliberately through size, weight, line height, measure, and spacing. Avoid too many levels or making every heading loud.

Typography should distinguish page purpose, primary content, supporting explanation, metadata, status, and actions. Metadata should not compete with the content it describes.

Expressive typography is appropriate when it reinforces storytelling or personality; it is not a substitute for hierarchy.

Review hierarchy, readability, coherence with Almsby, and behavior under localization and small screens.
