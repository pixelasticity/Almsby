# Visual Identity

Almsby should communicate clarity without sterility, craftsmanship without preciousness, trust without corporate heaviness, simplicity without shallowness, confidence without hype, and personality without visual noise.

## Emotional outcomes

| Outcome | Visual implication |
| --- | --- |
| Craftsmanship | intentional typography, detail, proportion, presentation |
| Pride | polished presentation worthy of showing customers |
| Trust | restraint, legibility, predictable hierarchy, visible state |
| Simplicity | low initial cognitive load and progressive disclosure |
| Authenticity | maker voice and product character remain visible |
| Confidence | clear primary action and understandable status |

## Distinctiveness

Distinctiveness should emerge from a consistent combination of typography, spacing rhythm, composition, content emphasis, imagery treatment, interaction behavior, and restraint—not novelty for novelty's sake.

## Anti-generic test

Ask whether the screen could plausibly belong to another generic SaaS product. If yes, identify concrete decisions that make it recognizably Almsby and explain why those decisions are useful.
