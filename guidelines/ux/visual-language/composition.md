# Composition

Composition should make the user's intended destination obvious before the user studies individual controls.

Every meaningful screen should have a clear primary purpose, dominant anchor, secondary priorities, appropriately receding support information, and a clear next action where applicable.

## Prefer transformation over accumulation

Before adding UI, consider removing, combining, reordering, shortening, grouping, or changing emphasis.

Cards are a grouping mechanism, not a default visual grammar. Every card should communicate a meaningful relationship.

## Review questions

- What does the eye see first?
- What does it see second?
- Can the user identify the primary action without searching?
- Which elements could disappear without loss?
- Does the composition express the product's purpose rather than its implementation?
