# Interaction

Make the next meaningful action obvious. Distinguish primary, secondary, and destructive actions. Show meaningful state changes. Preserve user control around consequential operations.

Every meaningful interactive component should intentionally address applicable default, hover, focus-visible, active, disabled, loading, success, error, and empty states.

Feedback should answer: what happened, did it succeed, and what can the user do next?

Accessibility is part of interaction quality, not post-processing.
