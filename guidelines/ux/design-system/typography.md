# Typography

Typography establishes hierarchy, readability, tone, and information density.

## Rules

- Define a small, intentional type scale.
- Use hierarchy to communicate task structure before relying on color or decoration.
- Optimize body text for comfortable reading.
- Treat data-heavy compliance interfaces differently from editorial story content where appropriate.
- Preserve readable line lengths.
- Verify long labels and translated strings.
- Do not introduce one-off font sizes without a documented reason.

## Review

Typography should be evaluated in context: content length, hierarchy, viewport size, locale, and interaction state all matter.
