# Color

Color communicates hierarchy, state, emphasis, and brand.

## Rules

Use semantic roles rather than scattering raw color values:

- background
- surface
- text
- muted text
- border
- accent
- success
- warning
- error
- informational

Color must not be the sole carrier of important meaning.

User-provided brand/accent customization must remain within the product's usability and accessibility constraints.

Compliance or validation states should remain understandable without requiring the user to memorize a color code.
