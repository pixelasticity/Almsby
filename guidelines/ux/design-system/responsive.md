# Responsive Foundations

Responsive behavior should preserve task hierarchy and usability across supported viewport sizes.

## Principles

- Design around content and task needs, not device names alone.
- Preserve primary actions.
- Reflow rather than simply scale where necessary.
- Avoid horizontal scrolling for ordinary task content.
- Ensure forms, tables, navigation, media, and status messages remain understandable.
- Test meaningful interaction states at representative narrow and wide viewports.

Feature-specific responsive decisions belong in the feature design plan; reusable behavior belongs here.
