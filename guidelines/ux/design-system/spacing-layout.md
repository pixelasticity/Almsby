# Spacing & Layout

Spacing should create predictable rhythm and clarify relationships between content.

## Rules

- Prefer a consistent spacing scale.
- Use grouping and whitespace to establish hierarchy.
- Keep primary actions visually discoverable.
- Avoid density that makes complex workflows harder to understand.
- Avoid excessive whitespace that separates related information.
- Responsive changes should preserve information hierarchy rather than merely shrink desktop layouts.

Reusable layout primitives should express the design system; page-specific composition belongs in feature design plans.
