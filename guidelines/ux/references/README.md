# Design References

References provide visual evidence and vocabulary; they are not templates.

Each reference should document what quality is being studied, why it is relevant, what should not be copied, and which Almsby surfaces it may inform.

Prefer a small, high-quality reference set over a large moodboard. A reference that cannot change a concrete design decision does not belong here.
