# Design Baselines

Baselines are canonical renderings of real Almsby interfaces used to detect visual drift and evaluate whether changes preserve or improve coherence.

A baseline records surface, route, viewport, locale, meaningful state, capture date, rationale, and known limitations.

A visual change is not rejected merely because it differs from a baseline. Evaluate whether the difference improves or harms the documented experience.
