# Responsive Verification

1. Identify the primary flow affected.
2. Test representative desktop and narrow/mobile viewports.
3. Inspect hierarchy, content wrapping, controls, navigation, forms, media, and action visibility.
4. Check for horizontal overflow, clipping, and overlap.
5. Verify responsive changes preserve interaction hierarchy.
6. Capture screenshots for meaningful visual differences or failures.

**Pass:** the primary task remains usable at supported viewport sizes with no critical clipping, overflow, inaccessible control, or broken hierarchy.

**Evidence:** record viewport dimensions, browser/device emulation details, screenshots where useful, and unresolved risks.
