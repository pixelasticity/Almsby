# Quality Protocols

Protocols are reusable procedures for establishing evidence.

A protocol should be repeatable, scoped, explicit about prerequisites and environments, explicit about failure handling, and clear about the evidence artifact to retain.

## Protocol selection

The Project Manager selects protocols based on the changed surface.

Examples:

- barcode/Digital Link → automated verification + physical scan
- public story page → browser + accessibility + responsive + visual review
- UX/copy → UX/product review + constitution/persona check
- i18n → locale parity + rendered-language review
- schema/data → migration verification + regression suite
- consequential AI behavior → decision/review evidence

Do not run irrelevant protocols mechanically. Record applicability in run evidence.
